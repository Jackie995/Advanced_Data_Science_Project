## Advanced Data Science Project

Data science project exploring immigration-related trends using public datasets, with analysis and modeling work captured in notebooks.

### Project report

- **Final report (PDF)**: [`Project Report.pdf`](./Project%20Report.pdf)

### Repository structure

- **Notebooks**: `Notebooks/` (EDA, cleaning, analysis)
- **Data**: `Data/` (raw/processed datasets and notes)

### Data sources

- **ICE historical data (2012–2023)**: [Kaggle – ICE 2012–2023 Historical Data](https://www.kaggle.com/datasets/bwandowando/ice-2012-2023-historical-data)
- **US immigration statistics (1980–2021)**: [Kaggle – US Immigration Statistics 1980–2021](https://www.kaggle.com/datasets/justin2028/us-immigration-statistics-1980-2021)
- **Global population & migration**: [Kaggle – Global Population and Migration Dataset](https://www.kaggle.com/datasets/hashimkhanwazir/global-population-and-migration-dataset)
- **Visa statistics**: [U.S. Department of State – Visa Statistics Annual Reports](https://travel.state.gov/content/travel/en/legal/visa-law0/visa-statistics/annual-reports.html)
- **GDP per capita**: [World Bank – NY.GDP.PCAP.CD](https://data.worldbank.org/indicator/NY.GDP.PCAP.CD)

### How to run (quickstart)

Open the notebooks in `Notebooks/` (Jupyter / VS Code / Cursor). Each notebook may be structured differently, it may use local data, or it may use data from Kaggle's API. If a notebook expects local data files, make sure the corresponding datasets exist under `Data/` with the same filenames used in the notebook.
